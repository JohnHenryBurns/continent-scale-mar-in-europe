# Continent-Scale MAR in Europe

**Banking the Flood** — a concept white paper on continuous, distributed managed aquifer recharge (MAR) as seasonal storage for Europe's drying rivers: divert a modest fraction of winter and flood flows into distributed aquifer storage across the major basins, and let it return as raised summer baseflow for navigation, cooling, and ecosystems.

- **Read the paper:** https://johnhenryburns.github.io/continent-scale-mar-in-europe/
- **Word version:** [Banking_the_Flood_White_Paper.docx](Banking_the_Flood_White_Paper.docx)

Status: working draft, August 2026. Basin-scale screening figures are the authors' estimates; costs, precedents, and event data are grounded in the sources listed in the paper.
